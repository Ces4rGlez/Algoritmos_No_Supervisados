¿Cómo interpretar este gráfico?

Ejes X/Y (PCA): El algoritmo comprimió todas las características numéricas seleccionadas en 2 dimensiones usando Análisis de Componentes Principales, conservando la mayor varianza posible.

Colores (Clústeres): Cada punto es una persona. Los del mismo color pertenecen al mismo clúster — el algoritmo los descubrió matemáticamente sin etiquetas.
